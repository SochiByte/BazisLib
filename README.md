# SochiCabinetMaker

## Описание

SochiCabinetMaker — открытый исследовательский проект по автоматизации проектирования корпусной мебели.

Проект состоит из двух взаимосвязанных направлений:

1. Исследование возможностей БАЗИС 2026.
2. Разработка собственной библиотеки автоматического построения мебели.

Главная цель проекта — создать хорошо документированную платформу, позволяющую проектировать мебель программно.

---

# Структура проекта

## docs/

Документация проекта.

Содержит описание архитектуры, исследования API, результаты реверс-инжиниринга, инструкции и справочные материалы.

---

## probes/

Исследовательские программы.

Каждый probe предназначен для изучения одной конкретной возможности среды выполнения.

Все эксперименты сначала появляются здесь.

---

## runtime/

Адаптеры к конкретным CAD-системам.

В настоящее время основной адаптер — БАЗИС 2026.

В дальнейшем могут быть добавлены другие системы.

---

## core/

Ядро библиотеки.

Не содержит знаний о мебели.

Здесь располагаются:

- базовые классы;
- коллекции;
- геометрия;
- математика;
- единицы измерения;
- проверки;
- вспомогательные функции.

---

## objects/

Описание всех объектов мебели.

Каждый объект отвечает только за себя.

Например:

- панель;
- фасад;
- ящик;
- полка;
- столешница;
- материал.

---

## machining/

Механическая обработка.

Содержит алгоритмы построения:

- присадки;
- пазов;
- фрезеровки;
- кромления;
- подготовки к ЧПУ.

---

## builders/

Автоматические построители мебели.

Здесь находятся алгоритмы создания готовых изделий.

Например:

- кухня;
- шкаф;
- комод;
- тумба.

Builder использует объекты из objects/.

---

## standards/

Правила проектирования.

В этом каталоге находятся стандарты:

- технологические зазоры;
- размеры;
- материалы;
- крепёж;
- правила проектирования.

Изменение стандартов не требует изменения алгоритмов.

---

## library/

Готовые библиотеки.

Повторно используемые компоненты:

- шаблоны;
- типовые узлы;
- модули;
- пресеты.

---

## examples/

Примеры использования библиотеки.

Каждый пример демонстрирует решение одной задачи.

---

## tests/

Автоматические проверки.

Все новые возможности сопровождаются тестами.

---

## scripts/

Служебные программы проекта.

Используются для генерации документации, проверки структуры и других сервисных задач.

---

## tools/

Вспомогательные утилиты разработчика.

Не являются частью библиотеки.
