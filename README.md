# BazisLib

Исследовательская библиотека для автоматизации проектирования корпусной мебели через скриптовый движок БАЗИС-Мебельщик 2026.

## Описание

Проект решает личную проблему: отсутствие публичной документации и инструментов для программного управления БАЗИС-Мебельщиком. Включает исследования встроенного JavaScript runtime, реверс-инжиниринг `ScriptEditor.dll`, прототипы доступа к объектам и документацию найденных возможностей.

**Целевая платформа:** БАЗИС-Мебельщик 2026 Online (Windows only)  
**Скриптовый движок:** на базе Node.js 22.14.0  
**Статус:** Активное исследование (ACTIVE RESEARCH)

## Ключевые области исследования

1. **Встроенный JavaScript runtime** — исследование возможностей и ограничений
2. **Объектная модель БАЗИС** — `Model`, `Application`, `Document`, `Editor`
3. **Нативные типы** — `TObject3D`, `T3DObjectList`, `TFurnPanel`, `TFurnAsm`
4. **COM Automation** — `NewCOMObject()`, `Scripting.FileSystemObject`, `WScript.Shell`
5. **Dispatch** — обёртки над COM-объектами с `__vars`, `__methods`, `__type`
6. **DISPID** — идентификаторы методов для прямого вызова
7. **`ScriptEditor.dll`** — реверс-инжиниринг через Ghidra

## Установка

Проект не требует установки зависимостей — используется чистый JavaScript, встроенный в скриптовый движок БАЗИС 2026.

**Требования:**
- БАЗИС-Мебельщик 2026 Online (Windows)
- Скриптовый редактор (входит в БАЗИС)
- Для реверс-инжиниринга `ScriptEditor.dll`: Ghidra 12.1.2+

## Использование

### Запуск исследовательских программ

Все пробы (`probes/`, `scripts/`) запускаются внутри скриптового редактора БАЗИС 2026:

1. Открыть БАЗИС-Мебельщик 2026
2. Перейти в редактор скриптов
3. Загрузить файл из папки `probes/` или `scripts/`
4. Выполнить
5. Результаты сохраняются в `output/` (исключена из Git)

### Результаты исследования

Все результаты документированы в `docs/research/`. Каждый факт имеет статус:
- **VERIFIED** — подтверждён экспериментом
- **DOCUMENTED** — указан в документации БАЗИС
- **HYPOTHESIS** — предположение, требующее проверки

## Процесс разработки

Проект создан с помощью ИИ-агента. Я управлял процессом: формулировал задачи, валидировал результат, вносил корректировки.

**Ключевые проблемы:**
- Скриптовый движок БАЗИС 2026 не документирован
- Отсутствие публичного API для доступа к объектам
- Необходимость реверс-инжиниринга через Dispatch-дескрипторы
- Ошибки `Invalid class typecast` при попытках перечисления объектов

**Использованные инструменты:**
- Ghidra 12.1.2 — для реверс-инжиниринга `ScriptEditor.dll`
- Qwen Code CLI — для анализа и генерации кода
- БАЗИС-Мебельщик 2026 Online — целевая среда выполнения
