# BazisLib

Библиотека для автоматизации проектирования корпусной мебели через скриптовый движок БАЗИС 2026.

## Описание

Проект решает личную проблему: отсутствие открытой библиотеки для программного проектирования мебели через БАЗИС-Мебельщик. Включает исследования скриптового движка, прототипы доступа к объектам и документацию реверс-инжиниринга.

Ключевые особенности:
- Исследование скриптового движка БАЗИС 2026 (на базе JavaScript)
- Доступ к объектам через COM-мосты и Dispatch-дескрипторы
- Документация реверс-инжиниринга (18 фактов)
- Прототипы исследовательских программ (probes)

## Установка

Проект не требует установки зависимостей — используется чистый JavaScript, встроенный в скриптовый движок БАЗИС 2026.

## Использование

Исследовательские программы (probes) запускаются внутри скриптового редактора БАЗИС 2026:

```bash
# Открыть БАЗИС 2026
# Перейти в редактор скриптов
# Загрузить файл из папки probes/ или scripts/
# Выполнить
```

Тесты (tests/) проверяют базовые возможности скриптового движка:

```bash
node tests/test_001.js
```

## Процесс разработки

Проект создан с помощью ИИ-агента. Я управлял процессом: формулировал задачи, валидировал результат, вносил корректировки.

**Ключевые проблемы:**
- Скриптовый движок БАЗИС 2026 не документирован
- Отсутствие публичного API для доступа к объектам
- Необходимость реверс-инжиниринга через Dispatch-дескрипторы

**Использованные инструменты:**
- Qwen Code CLI — для анализа и генерации кода
- Cursor — для редактирования и отладки
- БАЗИС 2026 — целевая среда выполнения
