# AGENTS.md

## Архитектура проекта

- `probes/` — исследовательские программы для БАЗИС 2026
- `scripts/` — прототипы доступа к объектам через Dispatch
- `docs/research/` — результаты реверс-инжиниринга
- `docs/PROJECT_STATUS.md` — текущий статус исследования

## Принципы кода

- Чистый, читаемый код на JavaScript
- Комментарии на русском языке
- Каждый эксперимент — отдельный файл с префиксом (0001_, 0002_, ...)
- Результаты сохраняются в `output/` (исключена из Git)

## Специфика проекта

Проект работает внутри скриптового движка БАЗИС-Мебельщик 2026, а не в браузере или обычном Node.js.

**Ключевые ограничения:**
- Только Windows (БАЗИС работает только на Винде)
- Скриптовый движок на базе Node.js 22.14.0
- Доступ к объектам через Dispatch-дескрипторы
- Ошибки `Invalid class typecast` при перечислении коллекций

## Частые задачи

1. Исследование возможностей скриптового движка
2. Доступ к объектам через COM-мосты
3. Обработка Dispatch-дескрипторов
4. Реверс-инжиниринг `ScriptEditor.dll`
5. Документирование результатов

## Тестирование

Пробы запускаются внутри скриптового редактора БАЗИС 2026:

```
1. Открыть БАЗИС-Мебельщик 2026
2. Перейти в редактор скриптов
3. Загрузить файл из папки `probes/` или `scripts/`
4. Выполнить
5. Результаты сохраняются в `output/`
```
