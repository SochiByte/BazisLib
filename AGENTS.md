# AGENTS.md

## Архитектура проекта

- `probes/` — исследовательские программы для БАЗИС 2026
- `scripts/` — прототипы доступа к объектам через Dispatch
- `tests/` — автоматические проверки скриптового движка
- `docs/research/` — результаты реверс-инжиниринга

## Принципы кода

- Чистый, читаемый код на JavaScript
- Комментарии на русском языке
- Тесты для всех критических функций
- Исследования документируются в `docs/research/`

## Частые задачи

1. Исследование скриптового движка БАЗИС 2026
2. Доступ к объектам через COM-мосты
3. Обработка Dispatch-дескрипторов
4. Создание прототипов исследовательских программ

## Тестирование

node tests/test_001.js
node tests/test_002_output.js
node tests/test_003_console.js
