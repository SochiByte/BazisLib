# CLAUDE.md

## Предпочтения

- Язык: русский
- Стиль кода: JavaScript, чистый синтаксис без фреймворков
- Документация: стиль OpenBSD

## Тестирование

- Все изменения должны проходить тесты
- Запуск: `node tests/test_001.js`

## Стиль коммитов

- `feat:` новая функциональность
- `fix:` исправление ошибки
- `docs:` документация
- `test:` тесты
- `chore:` технические работы
- Сообщения на русском языке
