# Bazis 2026 External Automation Research

## Цель проекта

Исследование способов внешнего управления Базис-Мебельщик 2026.

Основная задача:

Найти способ обращаться к функционалу Базис 2026 извне, без использования только встроенного редактора скриптов.

Исследуются возможные механизмы:

- Script API;
- ScriptEditor.dll;
- экспортируемые функции DLL;
- внешние точки входа;
- callback-механизмы;
- возможные интерфейсы взаимодействия.

# Анализ структуры ScriptEditor.dll

Обнаружена глобальная область состояния:

DAT_02b6f7d0

Тип:

undefined8

Используется как указатель на внутренний объект ScriptEditor.

Найдено много обращений:

- FUN_027fce00
- ReleaseEditor
- PrepareSE
- CloseAfterBazis
- SetOnRunScriptCallback
- SetOnRunDebugScriptCallback
- UpdateLog
- ClearLog
- BringToFrontAndShow
- SetBazisWorkFolder

# Подтвержденные факты

## PrepareSE

Функция создает объект ScriptEditor.

После создания:

DAT_02b6f7d0 = указатель на объект

или

DAT_02b6f7d8 = указатель на объект PM-системы

В зависимости от режима.

Фрагмент:

MOV qword ptr [DAT_02b6f7d0],RAX

---

## RunSE

Экспорт:

RunSE

Назначение:

Запуск Script Engine.

Использует:

FUN_027fce00

которая получает внутренний объект ScriptEditor.

Также вызывает:

SEOpenFile

---

## SetOnRunScriptCallback

Экспорт:

SetOnRunScriptCallback

Получает два указателя через RCX.

Копирует их во внутренний объект:

DAT_02b6f7d0 + 0xe78

Фактически устанавливает callback.

---

## SetOnRunDebugScriptCallback

Устанавливает callback:

DAT_02b6f7d0 + 0xe88

---

## CloseAfterBazis

Использует:

DAT_02b6f7d0

Передает объект в:

FUN_027f1180

Вероятно освобождение ресурсов.

---

# Важное открытие

ScriptEditor.dll имеет собственный внутренний объект состояния.

Доступ к нему идет через:

DAT_02b6f7d0

Этот объект содержит поля:

+0xe70
+0xe78
+0xe88
+0xe98
+0xea8

которые используются как callback-поля.

---

# Текущая гипотеза

ScriptEditor.dll может предоставлять внешний интерфейс управления:

1. Создать ScriptEditor через PrepareSE.

2. Установить callback.

3. Передавать команды через RunSE.

4. Получать результаты через callback.

Но это пока гипотеза.

Не подтверждено:

- полный формат параметров;
- структура объекта DAT_02b6f7d0;
- назначение всех callback;
- возможность вызова напрямую из внешнего приложения.
