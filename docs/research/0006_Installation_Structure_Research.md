# Исследование структуры установки

БАЗИС-Мебельщик 2026 Online

---

# Цель исследования

Исследовать файловую структуру стандартной установки
БАЗИС-Мебельщик 2026 Online.

Основные задачи:

* определить расположение компонентов программы;
* найти SDK;
* найти внешние API;
* найти инструменты автоматизации;
* найти примеры скриптов;
* найти дополнительные средства взаимодействия
  с БАЗИС;
* определить назначение отдельных каталогов и файлов.

---

# Факт №1

## Исследование каталога Tools

---

## Каталог

Исследованный каталог:

```text
C:\Program Files\BazisSoft\Bazis\Tools
```

---

## Результат

В каталоге обнаружены следующие исполняемые файлы:

```text
AnyDesk.exe

Kontur_Dostup_Abonent.exe
```

Обнаруженные программы относятся к средствам удалённой
поддержки.

---

## Не обнаружено

В исследованном каталоге `Tools` не обнаружены:

```text
SDK

примеры скриптов

внешние API-инструменты

средства автоматизации
```

---

# Вывод

В стандартной установке БАЗИС-Мебельщик 2026 Online
каталог:

```text
C:\Program Files\BazisSoft\Bazis\Tools
```

не содержит отдельного SDK, примеров скриптов,
внешних API-инструментов или готовых средств
автоматизации.

Это заключение относится только к исследованному
каталогу `Tools`.

---

# Важное ограничение результата

Отсутствие SDK и инструментов автоматизации
в каталоге `Tools` НЕ доказывает отсутствие:

* JavaScript API;
* внутренних API;
* native API;
* COM/OLE Automation;
* API внутри DLL;
* других внешних способов управления;
* средств автоматизации в других каталогах установки.

---

# Значение для исследования

Каталог:

```text
C:\Program Files\BazisSoft\Bazis\Tools
```

исключён как очевидное место расположения
отдельного SDK или готового набора внешних
инструментов автоматизации.

Поиск необходимо продолжить в других компонентах
установки БАЗИС.

---

# Следующие направления

Необходимо исследовать:

1. основной каталог установки БАЗИС;
2. подкаталоги с DLL;
3. `ScriptEditor.dll`;
4. другие DLL, связанные со скриптами;
5. конфигурационные файлы;
6. возможные SDK-компоненты в других каталогах;
7. документацию;
8. реестр Windows;
9. COM-регистрацию;
10. параметры запуска;
11. возможные внешние интерфейсы.
