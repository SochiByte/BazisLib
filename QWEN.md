2. Написать код с комментариями на русском
3. Добавить/обновить тесты
4. Обновить документацию
5. Сделать коммит с conventional commit

## Частые ошибки

1. Скриптовый движок БАЗИС 2026 не поддерживает `require()` → используйте `importScripts()`
2. Нет доступа к `console.log()` → используйте `output.write()`
3. Нет доступа к `process.exit()` → используйте `return` или `throw`
4. Dispatch-дескрипторы требуют специальной обработки → см. `docs/research/0007_Dispatch_Descriptor_Research.md`

## Специфика проекта

Проект работает внутри скриптового движка БАЗИС 2026, а не в браузере или Node.js. Ограничения:
- Нет стандартной библиотеки
- Нет модульной системы (кроме `importScripts()`)
- Доступ к объектам только через COM-мосты
